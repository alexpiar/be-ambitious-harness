# Scenario: generic

For tasks that fit no other scenario, or a mix without a clear center. Gives minimal hints; if the analysis shows where the result lives — switch to the specialized scenario.

## Analysis hints

**Point 1 — goal and bars.** Three questions that work for any task: what should happen after the result; who will use it and how; what happens if the task is not done. The ambitious bar is one of three moves: an end state instead of a step; removing the cause instead of the symptom; a way that makes repeating this task unnecessary.

**Gate check.** Unclear which check fits — ask: "what is the cheapest action after which it is clear whether the ambitious path is worth the expensive continuation?" No answer — no check, the scheme is baseline.

**Point 2 — improvements.** Describe the task as action and result, not artifact. The description usually shows which discipline owns the method. Assumption to check — the one the task presents as fact without a source.

**Point 3 — grounds.** What in the task is a summary, and what is it made from? Request the source of the summary.

**Point 4 — verification.** If no acceptance criterion comes to mind — the goal is undefined; return to point 1. Independent verification at minimum: another agent on another model with criteria and result, without the worker's reasoning.

## Traps

- **Generic as evasion.** If the task is 70% about data but "also text" — it is `data-analysis`, not generic.
- **Bar without a goal.** An ambitious bar not tied to "what should happen" is just more work.

## For the worker

- Start with the gate check, if any. Log the outcome before other work.
- Every claim — with evidence. Without evidence — under "unverified".
- Read section 6 criteria, do not interpret. If a criterion is inapplicable — say so in the report, do not adapt.
- Hand over what section 5 specifies, plus the log.

## Example of two bars

Task: "Prepare materials for a meeting with an investor."

- Baseline: materials per the brief — a deck, figures with sources, answers to expected questions.
- Ambitious: goal — the investor decides at the meeting rather than "will think about it"; check — 3 conversations with people who have seen similar pitches, about which question stalls the decision (limit — 2 hours; criterion — ≥2 of 3 name the same type of question → the materials are built around it).
