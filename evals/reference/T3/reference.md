# Эталон T3 · code-engineering · тест до фикса

Постановка (`evals/tasks.md`): «Приложение падает при открытии настроек на некоторых устройствах. Почини». Приложен репозиторий и три отчёта о краше. Режим: сохранить масштаб.

Материалы — фикстура прогона 21.10: `evals/runs/2026-10-21-gate/fixtures/t3-acme-settings/` (дерево `5823e994…`), скрытый оракул — `evals/runs/2026-10-21-gate/fixtures/hidden/t3-hidden.test.js` (9 тестов, sha256 `fdfae773…eef9`). Требование о строках Region и Currency взято из раздела 2 промпта T3-A: «—» в обеих строках при локали без региона.

Файлы: `prompt.md` — план; `journal.md` — журнал с выводами команд по порядку; `test/settings-locale-without-region.test.js` — новый тест; `fix.diff` — фикс, только исходники; `check.sh` — весь эталон одной командой.

## Разбор

**Тип и сценарий.** `code-engineering`: результат — фикс с тестом.

**Цель за постановкой.** Устранить причину падения у пользователей из отчётов (`de`, `pt`, `fil`, Android 11/12, 351 пользователь за 7 дней), не меняя экран для остальных.

**Предположение для проверки.** Что «некоторые устройства» — это локаль без региона, а не модель или версия ОС. Стек во всех трёх отчётах одинаковый и указывает на `regionOf`; воспроизведение на синтетических профилях подтверждает предположение.

**Две планки.**
- Базовая: краш воспроизведён детерминированно, тест падает до фикса и проходит после, фикс в разборе локали, все тесты зелёные, вывод для `devices/` не меняется.
- Амбициозная, одной строкой: контракт device-профиля (класс «нет поля в профиле»); в режиме «сохранить масштаб» не берётся.

**Схема — базовая; входной проверки нет.** Ветка одна, проверять перед ней нечего. Воспроизведение «детерминированно» — первый шаг базовой работы с остановкой при неудаче, а не gate.

## Вопросы человеку

1. Что показывать в Region и Currency при локали без региона? Ответ дан до работы: «—» в обеих строках (раздел 2).
2. Есть ли реальный профиль с затронутого устройства: точная строка `locale` и наличие `storage` и `screen`? Без него форма `pt_BR` и аудит остаются непроверенными.

## Первые действия

1. На исходном коде: `npm test`, `open-screen` для трёх `devices/*.json` — эталон «до».
2. Воспроизведение: `openScreen('settings', …)` с `de`, `pt`, `fil`, по 10 запусков — 30 из 30 падений, тот же стек.
3. Новый тест; на исходном коде падает той же TypeError; коммит теста.
4. Фикс в `regionOf` и строках секции `region`; `npm test` — 8 из 8.
5. Откат исходников при сохранённом тесте — падение; `open-screen` до и после совпадает; граничный ввод; аудит.

## Что сдано

- `fix.diff`: `regionOf` возвращает `null` без второго подтега; при `null` строки Region и Currency — «—». 6 строк в двух файлах; существующие тесты и `devices/*.json` не тронуты.
- `test/settings-locale-without-region.test.js`: 3 теста через `openScreen`, без моков.
- Проверка без автора, из корня репозитория:
