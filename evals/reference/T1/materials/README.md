# Материалы эталона T1 — синтетика для эталона

Не данные магазина. Набор придуман, чтобы показать, что критерий входной проверки T1 вычисляется и даёт исход; числа подобраны под исход «пройдена». На настоящих данных исход может быть любым из трёх — задача проверяет порядок действий, а не исход.

- `funnel.csv` — воронка оформления за 4 недели: неделя × устройство × шаг (`cart` → `delivery` → `payment` → `confirm` — экран подтверждения показан → `placed` — заказ оформлен), число сессий. 60 строк.
- `sessions.csv` — 10 записей сессий с уходом с экрана подтверждения, случайная выборка; коды причин — из списка, записанного до просмотра (`../prompt.md`, раздел 4).

Расчёт: `python3 -I ../gate.py` из этой папки или `python3 -I evals/reference/T1/gate.py` из корня.
