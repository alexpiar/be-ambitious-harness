# Журнал — T6 · подарок коллеге (ответы двух людей — синтетика для эталона)

## 1. Материалы
- Дата дня рождения и двое, кто знает коллегу лучше (руководитель, сосед по проекту), — от человека. Ответы ниже придуманы для эталона.

## 2. Проверка
- Вопрос из раздела 4 отправлен каждому отдельно.
- Ответ 1 (руководитель): «Любит кофе, кажется, ездит на велосипеде. Только не алкоголь».
- Ответ 2 (сосед по проекту): «Играет в настольные игры по пятницам. Про остальное не знаю».

```
GATE
действие:            два человека по отдельности ответили на вопрос из раздела 4
материалы:           ответы руководителя и соседа по проекту
наблюдаемый результат: ответ 1 — кофе, велосипед; запрет — алкоголь. Ответ 2 — настольные игры. Общего интереса нет
критерий (как записан): оба независимо называют один и тот же конкретный интерес. Обоснование: догадка одного человека о малознакомом коллеге ненадёжна; совпадение двух независимых ответов — минимальное свидетельство.
предел затрат:       10 минут на два сообщения; ответ — не позже чем за 3 дня до дня рождения
фактические затраты: 2 сообщения; оба ответа получены в срок
исход:               не пройдена
следствие:           базовая ветка: универсальный подарок и открытка; режим «амбициозное расширение» исход не меняет
```

## 3. Базовая ветка
- Выбрано: угощение на всю команду в день рождения и открытка с подписями 6 коллег — по строке от каждого. Ориентир цены 2500–4000 ₽ — оценка, не проверена; проверить при заказе.
- Тест на опровержение: алкоголя в подарке нет.
