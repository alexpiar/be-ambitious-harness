# Шаблон промпта для воркера

Семь разделов, фиксированный порядок. Раздел 4 — только для условной схемы. Промпт самодостаточен: воркер не видит разбор.

## Что идёт в каждый раздел

1. **Цель и результат** — цель; что должно стать возможным или произойти после результата; выбранная схема (базовая / амбициозная сразу / условная) и планка. Для новой или сложной задачи амбициозная планка сформулирована как цель-исследование, число при ней — гипотеза.
2. **Обязательные требования и границы** — дословно из исходной задачи. Противоречия между требованиями — отдельной строкой, без молчаливого разрешения.
3. **Материалы и доступы** — два списка: необходимые и необязательные. Строка: «Если необходимых нет — запросить у меня до начала работы».
4. **Входная проверка** — пять атрибутов из `core/gate.md`, три исхода с действиями, правило очерёдности.
5. **Подход и этапы** — только принятые улучшения; вопрос → метод → проверяемый результат; что передаётся.
6. **Критерии приёмки и проверка** — критерии измеряют цель, не прокси; исходный уровень или эталон; способ независимой проверки; тест на опровержение; что считать подгонкой под метрику.
7. **Завершение и отчёт** — условия завершения; формат отчёта по `core/report-format.md`; требование перечислить допущения, непроверенные выводы и блокеры.

## Скелет

```
<промпт>
Сценарий: [имя файла из scenarios/]

## 1. Цель и результат
Цель: …
Что должно стать возможным: …
Схема: … — планка: …

## 2. Обязательные требования и границы
— …
Противоречия: нет | …

## 3. Материалы и доступы
Необходимые: …
Необязательные: …
Если необходимых нет — запросить у меня до начала работы.

## 4. Входная проверка   (только для условной схемы)
Действие и материалы: …
Наблюдаемый результат: …
Критерий прохождения (зафиксирован, пересмотру не подлежит): …
Предел затрат: …
Пройдена → …
Не пройдена → …
Данных недостаточно → …
Работа амбициозной ветки начинается после зафиксированного исхода.

## 5. Подход и этапы
…

## 6. Критерии приёмки и проверка
Критерии: …
Эталон / исходный уровень: …
Независимая проверка: …
Тест на опровержение: …
Подгонка под метрику — что считать ею: …

## 7. Завершение и отчёт
Завершено, когда: …
Отчёт по core/report-format.md: результат и проверка без автора; схема и исход проверки; обе планки; допущения; непроверенные выводы; блокеры.
</промпт>
```
