# Форматы отчётов

Одинаковые поля у воркера и верификатора — чтобы их можно было сложить рядом.

## Отчёт воркера

```
РЕЗУЛЬТАТ
что передано: [файлы, ссылки, артефакты]
проверка без автора: [команды, каждая одной строкой, — по блоку «Для воркера» сценария]

СХЕМА
выбранная: базовая | амбициозная сразу | условная
GATE: [блок из core/gate.md, если был]

ПЛАНКИ (недобор базовой — дефект; недобор амбициозной — ожидаемый результат)
базовая: выполнена | не выполнена (почему)
амбициозная: достигнута | не достигнута | не выполнялась (почему) — что узнали

СВИДЕТЕЛЬСТВА
утверждение → чем подтверждено (файл / тест / число / источник)
…
не проверено: [утверждения без подтверждения]

КРИТЕРИИ (самопроверка — не заменяет верификатора)
критерий → измерено как → значение → выполнен / нет / не измерить

ДОПУЩЕНИЯ
…

БЛОКЕРЫ
…

ДЛЯ ВЕРИФИКАТОРА
что стоит проверить иначе, чем проверил я: …
```

## Вердикт верификатора

```
ВЕРДИКТ: принять | принять с оговорками | отклонить (стадия 1 | 2)

ТРЕБОВАНИЯ (раздел 2, дословно)
требование → выполнено / нарушено / не проверить → свидетельство

КРИТЕРИИ (раздел 6)
критерий → мой способ измерения → моё значение → значение воркера → совпадает / расходится

ОПРОВЕРЖЕНИЕ
тест: … → результат: …

ПОДГОНКА
проверено: [способы из раздела 6 + один свой] → найдено / не найдено

GATE
gate-check --strict: итог, строки FAIL
критерий совпадает с разделом 4: да / нет
исход зафиксирован до амбициозной работы: да / нет
исход соответствует критерию: да / нет

СООТВЕТСТВИЕ ЦЕЛИ (раздел 1)
что должно стать возможным → достигнуто / нет / не проверить → свидетельство

НЕ ПРОВЕРЕНО
что и почему; что нужно, чтобы проверить

ДЕФЕКТЫ
один дефект — одна строка — одно предложение по исправлению
```

## Отчёт для человека (собирает оркестратор)

Пять строк: что сделано; какая схема и исход проверки; вердикт верификатора; что не проверено; какое решение требуется от человека.
