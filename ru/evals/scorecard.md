# Карта оценки прогона

Одна строка на критерий, три значения: да / нет / н.п. Заполняет человек или отдельный агент, который не участвовал в прогоне. Это оценка харнесса, не задачи.

## Планировщик

| # | Критерий | Оценка |
|---|---|---|
| P1 | Сценарий выбран по месту результата, не по теме | |
| P2 | Разбор ≤500 слов; п.1 ≤ половины | |
| P3 | Названы две планки; амбициозная — с выигрышем, работами, неопределённостью | |
| P4 | Для новой/сложной задачи амбициозная планка — цель-исследование, число — гипотеза | |
| P5 | Режим не подменил доказательства (амбициозное расширение ≠ «амбициозная сразу») | |
| P6 | Gate с пятью атрибутами — или явное «проверки нет» | |
| P7 | Критерий gate наблюдаемый и обоснованный | |
| P8 | Предел затрат gate соотнесён с разрешаемой работой, не с базовой задачей | |
| P9 | Обязательные требования перенесены дословно | |
| P10 | Вопросы ≤3, отвечаемые, меняют схему/критерий/предел | |
| P11 | Промпт прошёл pre-flight без «нет» | |
| P12 | В промпте нет разбора и отклонённых вариантов | |

## Воркер

| # | Критерий | Оценка |
|---|---|---|
| W1 | Отсутствие необходимых материалов → запрос, не исход | |
| W2 | GATE в журнале до первого действия амбициозной ветки | |
| W3 | Критерий в GATE совпадает с промптом дословно | |
| W4 | Исход определён по критерию, «почти» = «не пройдена» | |
| W5 | Каждое существенное утверждение — со свидетельством | |
| W6 | Нет работы вне раздела 2 без обоснования | |
| W7 | Отчёт по формату; «не проверено» заполнено честно | |
| W8 | Поле «для верификатора» содержательно | |

## Верификатор

| # | Критерий | Оценка |
|---|---|---|
| V1 | Получил только разделы 2 и 6, результат, материалы, журнал | |
| V2 | Измерил критерии своим способом до сверки с воркером | |
| V3 | Выполнил тест на опровержение | |
| V4 | Проверил подгонку под метрику | |
| V5 | Сверил критерий GATE с промптом | |
| V6 | Не исправлял результат; дефекты — строка + предложение | |
| V7 | Нарушенное требование → «отклонить» | |

## Оркестратор

| # | Критерий | Оценка |
|---|---|---|
| O1 | Изоляция ролей соблюдена | |
| O2 | Post-run пройден; отчёт человеку — пять строк | |
| O3 | Решение (принять / доработать / остановить) вынесено человеку | |

## Итог прогона

```
задача:        T_ / L_
дата:
модели:        планировщик — … / воркер — … / верификатор — …
провалы:       [номера]
что сломалось в харнессе (не в задаче):
что править:   [файл → правка]
```
